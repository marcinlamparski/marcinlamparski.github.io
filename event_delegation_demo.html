// dwa sposoby obsługi kliknięcia w grupie elementów

SPOSÓB 1 forEach + addEventListener
🏔️1
🌊1
🌲1
🏖️1
← kliknij miniaturkę
Liczba listenerów: 4 (po 1 na każdym elemencie)
skrypt.js 
const miniatury = querySelectorAll('#galeria img');

miniatury.forEach(function(img, idx) {
  img.addEventListener('click', function() {
    pokazZdjecie(idx);
  });
});

// forEach wykona się 4 razy →
// przeglądarka zapamiętuje 4 osobne listenery
// (po 1 przypiętym do każdego elementu DOM)

🏔️0
🌊0
🌲0
🏖️0
← kliknij miniaturkę
Liczba listenerów: 1 (1 na rodzicu — zawsze!)
skrypt.js 
const galeria = getElementById('#galeria');
const miniatury = querySelectorAll('img');

galeria.addEventListener('click', function(e) {
  if (e.target.tagName === 'IMG') {
    const idx = [...miniatury].indexOf(e.target);
    pokazZdjecie(idx);
  }
});

// brak pętli → addEventListener wywołany 1 raz →
// przeglądarka zapamiętuje 1 listener na rodzicu
// (niezależnie od liczby miniaturek)

📊 Porównanie

Cecha forEach + addEventListener Delegacja zdarzeń
Liczba listenerów tyle co elementów (N) zawsze 1
Zużycie pamięci rośnie z liczbą elementów stałe
Dynamiczne elementy trzeba ponownie podpiąć działa automatycznie
Trudność kodu prostsza (brak e.target) wymaga sprawdzenia e.target
Zalecane gdy... mała, statyczna lista (ok na egzaminie) duże listy, galerie, dynamiczne treści
Jak działa delegacja? Zdarzenia w DOM „bąbelkują" w górę drzewa — kliknięcie na <img> automatycznie dociera też do rodzica <section>. Dzięki temu jeden listener na rodzicu „słyszy" kliknięcia wszystkich dzieci. Właściwość e.target mówi, który konkretny element faktycznie kliknął użytkownik.
