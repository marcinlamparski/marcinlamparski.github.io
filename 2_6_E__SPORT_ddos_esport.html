// 01 — podstawy

Czym jest atak DDoS?

DDoS (ang. Distributed Denial of Service — Rozproszona Odmowa Usługi) to cyberatak, w którym napastnik wysyła do serwera ofiary ogromną liczbę zapytań z wielu urządzeń jednocześnie. Celem jest przeciążenie infrastruktury tak, by legalni użytkownicy nie mogli korzystać z usługi.

DoS

Atak z jednego komputera. Łatwy do zablokowania — wystarczy zbanować jeden adres IP.

DDoS

Atak z tysięcy/milionów urządzeń. Trudny do zablokowania — adresy IP są różne i rozsiane po całym świecie.

Cele ataku

Wyłudzenie (okup), sabotaż konkurencji, protest, dywersja lub po prostu zniszczenie turnieju.

// 02 — jak to działa

Schemat ataku DDoS

Kanał C&C (dowodzenie)
Ruch ataku DDoS
Zainfekowane urządzenia (boty)
Przeciążony serwer

Jak to działa krok po kroku:
1. Atakujący infekuje tysiące urządzeń złośliwym oprogramowaniem — tworzą one botnet.
2. Przez serwer C&C (Command & Control) wysyła rozkaz: „atakujcie cel".
3. Wszystkie boty jednocześnie zasypują serwer ofiary pakietami danych.
4. Serwer nie jest w stanie obsłużyć tylu połączeń — przestaje odpowiadać.
5. Prawdziwi gracze tracą połączenie z turniejem.

// 03 — klasyfikacja

Typy ataków DDoS

🌊
Wolumetryczne
WARSTWA 3/4 — SIECIOWA

Zalewają łącze sieciowe ofiary ogromną ilością danych — jak wąż ogrodowy próbujący wypełnić ocean. Cel: całkowite zapchanie przepustowości łącza.

UDP Flood ICMP Flood DNS Amplification NTP Amplification
🔗
Protokołów
WARSTWA 3/4 — TRANSPORTOWA

Eksploatują słabości protokołów sieciowych (TCP, ICMP) i wyczerpują zasoby sprzętowe — tabele stanów zapór ogniowych i load balancerów.

SYN Flood Ping of Death Smurf Attack Fraggle Attack
🎯
Warstwy aplikacji
WARSTWA 7 — APLIKACJI

Najtrudniejsze do wykrycia — imitują prawdziwy ruch użytkowników. Atakują konkretne funkcje aplikacji webowych, zużywając zasoby serwera.

HTTP Flood Slowloris RUDY Attack DNS Query Flood

🔍 Szczegółowo: SYN Flood (najczęstszy atak w e-sporcie)

Normalnie połączenie TCP wymaga trójfazowego uzgadniania (3-way handshake): SYN → SYN-ACK → ACK.
W ataku SYN Flood: bot wysyła setki tysięcy pakietów SYN bez odpowiedzi ACK. Serwer czeka na potwierdzenia, które nigdy nie nadchodzą — jego kolejka połączeń się przepełnia i odmawia obsługi prawdziwych graczy.

// 04 — infrastruktura ataku

Jak działa botnet?

  • 01
    Infekcja urządzeń Hakerzy rozsyłają złośliwe oprogramowanie (malware) przez e-mail, pirackie gry, fałszywe programy. Użytkownik nie wie, że jego urządzenie jest zainfekowane.
  • 02
    Rejestracja w botnecie Po infekcji urządzenie łączy się z serwerem C&C (Command & Control) i czeka na rozkazy. Może to trwać tygodniami bez żadnych widocznych objawów.
  • 03
    Skala botnetu Duże botnety liczą miliony urządzeń: komputery, smartfony, routery, drukarki, smart TV — wszystko co ma połączenie z internetem.
  • 04
    Otrzymanie rozkazu ataku Właściciel botnetu wysyła komendę: „atakujcie IP X przez Y sekund". Wszystkie boty jednocześnie zaczynają zasypywać cel pakietami.
  • 05
    Trudność wykrycia Ponieważ każdy bot ma inny adres IP i pochodzi z innego kraju, proste blokowanie IP nie działa. Ruch ataku miesza się z legalnym ruchem.
// 05 — kontekst turniejowy

DDoS w świecie e-sportu

Turnieje e-sportowe to dziś wielomilionowe eventy — ataki DDoS stanowią dla nich poważne zagrożenie. Gracze, organizatorzy i sponsorzy tracą pieniądze i reputację gdy serwery padają. Przypadki ataków podczas turniejów CS2, LoL, DOTA 2 to nie teoria — to udokumentowana rzeczywistość.

⏱️

PRZERWY W GRZE

Mecze przerywane w połowie rundy. Gracze tracą koncentrację, wyniki są unieważniane lub powtarzane.

💰

STRATY FINANSOWE

Organizatorzy tracą na transmisji i reklamach. Pula nagród może być opóźniona lub w spornych okolicznościach.

📺

STREAMING OFFLINE

Tysiące widzów na Twitchu/YouTube traci transmisję. Wizerunkowe straty dla organizatora turnieju.

🏆

MANIPULACJA WYNIKAMI

Ataki mogą być wymierzone w konkretnego gracza (jego home IP) — nieuczciwa przewaga dla przeciwnika.

🔐

UJAWNIANIE IP

Przez wycieki IP (np. przez Discord czy stream) gracze sami stają się celem. Dlatego zawodowcy ukrywają swoje adresy.

⚖️

KONSEKWENCJE PRAWNE

Atak DDoS to przestępstwo kryminalne — art. 268a KK. Kara pozbawienia wolności do 3 lat.

🎮 Znane przypadki: Podczas turnieju ESL One 2019 gracze zgłaszali ataki DDoS wymierzone bezpośrednio w ich domowe sieci. W 2020 r. ataki na infrastrukturę Riot Games powodowały regularne problemy z serwerami rankingowymi. Organizacje jak LAN (Local Area Network) — gdzie gracze grają z jednej lokalizacji — są znacznie trudniejszym celem niż turnieje online.

// 06 — obrona

Metody ochrony przed DDoS

🛡️ DDoS MITIGATION SERVICE

Specjalistyczne usługi jak Cloudflare, Akamai lub AWS Shield filtrują złośliwy ruch zanim dotrze do serwera. Ruch jest „czyszczony" w centrach scrubbing.

CLOUDFLARE / AWS SHIELD / AKAMAI

🔀 LOAD BALANCING

Ruch rozdzielany jest między wiele serwerów. Nawet przy ataku nie jeden serwer, ale cała infrastruktura musi zostać przeciążona — dużo trudniejsze zadanie.

INFRASTRUKTURA ROZPROSZONA

📊 RATE LIMITING

Serwer ustala maksymalną liczbę połączeń z jednego IP w określonym czasie. Boty przekraczające limit są automatycznie blokowane.

OGRANICZENIE RUCHU / IP

🔍 ANOMALY DETECTION

Systemy AI analizują wzorce ruchu w czasie rzeczywistym. Nagłe skoki o 1000% to sygnał ataku — automatyczne uruchamianie ochrony.

AI / MACHINE LEARNING

🌍 ANYCAST ROUTING

Ten sam adres IP istnieje w wielu lokalizacjach na świecie. Ruch ataku jest rozpraszany geograficznie, żaden punkt nie zostaje przeciążony.

INFRASTRUKTURA GLOBALNA

🎮 OCHRONA GRACZY

VPN ukrywa prawdziwy adres IP gracza. Organizatorzy nie ujawniają IP serwerów turniejowych. W LAN-ach problem praktycznie nie istnieje.

VPN / IP HIDING / LAN EVENTS
